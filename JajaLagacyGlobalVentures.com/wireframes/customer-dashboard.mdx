The customer dashboard is the primary surface for buyers. It centralizes purchased tools, subscriptions, usage analytics, billing, and account security in a mobile-first responsive layout.

## Dashboard layout

```mermaid
flowchart LR
    subgraph Nav["Top Navigation"]
        Logo[Logo]
        Search[Search Catalog]
        Cart[Cart + Wallet Balance]
        Profile[Profile Menu]
    end

    subgraph Side["Sidebar"]
        S1[Overview]
        S2[My Tools]
        S3[Subscriptions]
        S4[Usage & History]
        S5[Billing]
        S6[Security]
        S7[Support]
    end

    subgraph Main["Main Content Area"]
        C1[Purchased Tools Grid]
        C2[Active Subscriptions]
        C3[Recent Activity Feed]
        C4[Quick Purchase Widgets]
        C5[Usage Charts]
    end

    Nav --> Side
    Side --> Main
```

## Mobile behavior

- Sidebar collapses into a bottom nav on screens under 768px.
- Quick Purchase widgets stack vertically with sticky category chips.
- Tables (history, subscriptions) switch to card lists on small screens.
