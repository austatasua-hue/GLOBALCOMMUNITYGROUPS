The recommended stack favors mature frameworks, horizontal scaling, and a modular service boundary so new categories plug in without rewrites.

## Stack summary

| Layer | Recommendation | Alternative |
| --- | --- | --- |
| Frontend | Next.js (React) | Nuxt (Vue) |
| Backend | NestJS (Node.js) | Laravel (PHP) |
| Database | PostgreSQL | MySQL 8 |
| Cache & Queue | Redis + BullMQ | Redis + Laravel Horizon |
| Search | Meilisearch | OpenSearch |
| Object storage | S3-compatible | Cloudflare R2 |
| Payments | Stripe, PayPal, Coinbase Commerce | Adyen, NOWPayments |
| SMS / virtual numbers | SMS-Activate, 5sim, Twilio | TextVerified, Vonage |
| Social boosting | Vendor APIs per platform | Aggregator SMM panels |
| Email | Postmark | SendGrid |
| Observability | OpenTelemetry + Grafana | Datadog |
| Hosting | AWS ECS / Fly.io | GCP Cloud Run |
